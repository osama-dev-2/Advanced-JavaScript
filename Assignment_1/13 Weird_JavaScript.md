1. this :

   هي تشير الى قيمة التي يتم تحديدها اثناء عمل invoke لدالة العادية
   مثلا لو سوينا invoke لدالة العادية عن طريق object مثلا user.invoke() فان ال this تشير الى الuser
   اما اذا كان نوع الدالة arrow فان ال this تشير الى قيمة ال this حق السكوب المحيط بها
   هي تسعدنا للوصول الي properties الكائن الذي تم عمل invoke لدالة العادية من خلاله

2. hosting:

   هو سلوك ال javascript الذي يجعل تعريفات دوال ال declaration متاحة قبل مكان كتابتها
   اما اذا اردنا الوصول الى متغير var قبل سطر تعريفة واسناد له قيمة فان قيمة تكون undefined  
   اما اذا كان المتغير let او const واردنا الوصول الية قبل سطر التعريف فانه يسبب خطاء

3.Closures in Loops :

هو سلوك يقوم بحفظ المتغيرات الموجوده في البيئة المحيط بالدالة
وعند تعريف دوال داخل loops وكان المتغير الخاص بال loops var فيكون يتم انشاء بيئة محيطة لكل دورة
واذا كان المتغير الخاص بال loops let يتم انشاء بيئة محيطة لكل دورة

4. bind / call / apply :

   هي دوال تساعدنا في التحكم بقيمة ال this عند استدعاء الدوال العادية

   call: تقوم باستدعاء الدالة مع تحديد قيمة ال this وارسال ال arguments بشكل منفصل

   apply : تعمل نفس call ولاكن ارسال ال arguments مصفوفة

   bind : تقوم بانشاء دالة جديدة مرتبطة بال this ويمكن استدعاء الداله لاحقا
